# Work item 102 (User Story): Free shipping on orders of 100 USD or more

**Paste this title when /start asks:** Free shipping on orders of 100 USD or more

## Description

As a customer, I want free shipping when my order is large enough, so that I am encouraged to buy more.

Orders whose subtotal is 100.00 or more (in the order's currency, before any discount) get free shipping. The order summary should say whether free shipping was applied, and the orders screen should show it clearly.

## Acceptance criteria

1. An order with a subtotal of 100.00 or more has a shipping charge of 0.00.
2. An order with a subtotal of exactly 100.00 qualifies.
3. An order with a subtotal below 100.00 still pays standard shipping (7.99).
4. The threshold uses the subtotal before any discount code is applied.
5. The order summary API response includes `freeShipping: true` or `false`.
6. On the orders screen, when free shipping applies, the shipping row shows `Free` instead of an amount.

## Notes from the engineer

- Comparing two `Money` values is not supported yet. That type lives in the shared library, which other products also use.
