# Work item 103 (Spike): Can one order contain items in different currencies?

**Use with:** `/spike 103 can one order contain items priced in different currencies`

## Question

Product is asking whether a single order could contain items priced in different currencies (for example USD and EUR). What would break today, and what are the options?

## What we need

- What happens today if an order has lines in two currencies.
- 2 or 3 options with rough effort.
- A recommendation.
